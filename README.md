# Агро-радар

Радар объявлений о продаже зерна в Telegram-чатах. Он слушает зерновые группы, ловит объявления «продам» по нужным культурам и регионам и **в ту же минуту** присылает их через Telegram-бота. Дубли из разных чатов отсекаются, все находки пишутся в журнал `radar_log.csv`.

## Возможности

- слушает публичные и частные группы Telegram (через клиентский API, библиотека Telethon)
- фильтр: слова продажи + культура, стоп-слова («куплю», «закупаем»), регионы
- одно объявление из нескольких чатов приходит один раз
- уведомления от бота: аккаунт радара только читает и ничего не пишет
- журнал находок в CSV для аналитики: сколько предложений по культурам и чатам
- выгрузка последних объявлений в Excel и статистика по чатам

## Файлы

| Файл | Что делает |
|---|---|
| `radar.py` | Агро-радар: слушает чаты, фильтрует, уведомляет, ведёт журнал |
| `radar_config.py` | настройки: чаты, слова, регионы, имя журнала |
| `dialogs.py` | список всех чатов аккаунта с их ID |
| `chat_parser.py` | последние объявления о продаже → `chats.xlsx` |
| `chat_stats.py` | какие чаты живые: объявления по чатам и культурам |
| `chat_radar.py` | учебная версия радара (неделя 3, день 5) |
| `practice/` | учебные парсеры: курсы ЦБ, погода, цитаты, каталог книг |

## Установка

1. Python 3.12 или 3.13.
2. Отдельный Telegram-аккаунт для радара, ключи `api_id` и `api_hash` на [my.telegram.org](https://my.telegram.org).
3. Установка:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
4. Скопируй `.env.example` в `.env` и впиши свои ключи, токен бота и свой ID.
5. В `radar_config.py` укажи свои чаты, культуры и регионы.

## Запуск

```
python dialogs.py   # первый вход: номер телефона и код из Telegram, затем список чатов
python radar.py     # радар работает, пока не нажмёшь Ctrl+C
```

## Безопасность

`.env` и `radar.session` дают полный доступ к аккаунту радара и в репозиторий не попадают (см. `.gitignore`). Радар только читает чаты: никаких рассылок и сообщений людям.
